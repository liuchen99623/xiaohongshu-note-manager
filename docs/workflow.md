# 完整工作流

```text
账号档案 → 内容简报 → 提示词预览 → AI 生成 → 人工核验 → 导出 → 排期 → 手动发布 → 数据复盘
```

## 1. 账号档案

记录定位、目标读者、调性、目标、禁用表达和可用素材。一个数据库可以保存多个账号，互不混淆。

## 2. 内容简报

每个简报固定关联一个账号，并明确主题、目标、图文/视频、真实素材和限制。缺少事实时，生成结果必须保留 `【待补充】`，不能自行编造。

## 3. 生成与核验

`prompt` 命令允许先检查发送给模型的内容。`generate` 只接受结构化 JSON，并校验标题数、分页或分镜等必要字段。模型输出仍需人工核对事实、版权、广告标识、敏感功效和时效性。

## 4. 导出与排期

内容包可导出 Markdown 或 JSON。排期模块只保存计划，不登录小红书，也不会点击发布。

## 5. 人工发布

发布前逐项确认：

- 事实、价格、时间和案例来自真实资料；
- 图片、音乐、字体和视频具有使用授权；
- 广告、合作、赠品、医疗、金融或 AI 内容按规则披露；
- 标题与封面没有夸张承诺；
- 用户本人确认最终版本和发布账号。

## 6. 数据复盘

发布后录入真实指标。每个内容包保存一份当前累计指标快照；再次录入会更新该快照，避免把同一篇笔记多个时间点的累计值重复相加。汇总只计算真实总量和可由这些数值直接得到的比例，不虚构行业基准。你可以把复盘教训写入下一份简报的限制条件，形成迭代闭环。
